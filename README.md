# Data Engineering Practice Projects

This repository contains small, self-built data engineering practice projects implemented using Python.  
The focus of these projects is to strengthen fundamentals in data extraction, transformation, loading (ETL), and working with structured data using databases.

These projects were built as part of my learning and preparation for software/data engineering roles.

---

## Projects Included

### 1. ETL Pipeline (Python, SQLite)
- Implemented a basic ETL workflow using Python.
- Extracted data from source files.
- Applied transformations such as cleaning and formatting.
- Loaded processed data into an SQLite database.
- Focused on modular code structure and data handling logic.

**Key Concepts:**
- ETL workflow
- Python scripting
- SQL & SQLite
- Data cleaning and transformation

---

### 2. API Data Pipeline (Python)
- Built a simple pipeline to fetch data from an external API.
- Parsed and processed API responses using Python.
- Stored structured results into a database.
- Handled basic error scenarios and data formatting.

**Key Concepts:**
- API data extraction
- JSON processing
- Python-based data pipelines
- Structured data storage
